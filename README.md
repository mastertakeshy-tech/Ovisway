# Ovi’s Way

**Ovi’s Way** es un videojuego de plataformas en 2D ambientado en ASOR. Ovi debe rescatar a Blue después de que el científico Charles Kim la lleve a su laboratorio. Para llegar hasta ella, recolecta madera, fabrica plataformas y esquiva los ataques de los robots que vigilan el camino.

## Cómo se juega

Recoge tres piezas de madera para fabricar una tabla. Puedes fabricar **una tabla por intento de nivel**. Lánzala para crear una plataforma suspendida y recupérala cuando necesites usarla en otro lugar.

| Tecla | Acción |
| --- | --- |
| **← / →** | Mover a Ovi |
| **Espacio / ↑** | Saltar |
| **X** | Lanzar la tabla |
| **C** | Recuperar una tabla cercana |
| **Z** | Disparar después de recoger el arma en el nivel 3 |

Los robots normales se derrotan con tres pisotones. Ovi rebota al caerles encima, lo que le permite volver a saltar sobre ellos o esquivar sus proyectiles.

La tienda del nivel 3 se abre al entrar en la caseta. Puedes comprar hasta dos mejoras con las monedas recogidas. Al reintentar o reiniciar un nivel, las monedas y las compras se reinician.

## Recorrido

| Etapa | Objetivo |
| --- | --- |
| **Tutorial** | Aprende a fabricar, lanzar y recuperar la tabla. Practica cómo esquivar al robot volador. |
| **Nivel 1 · Entrenamiento** | Usa la tabla para cruzar el escenario y llegar al portal. |
| **Nivel 2 · Ruta de ASOR** | Esquiva a los robots, recoge monedas y encuentra la llave del laboratorio. |
| **Nivel 3 · Laboratorio** | Recoge el arma, esquiva los disparos de Charles Kim y derrota al jefe para rescatar a Blue. |

## Abrir el proyecto

1. Descarga el archivo **.capx** incluido en el repositorio.
2. Ábrelo en **Construct 2**.
3. Ejecuta el proyecto desde **Menú principal** para jugar desde el inicio.
